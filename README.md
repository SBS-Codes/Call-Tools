# Ollama Function Calling Demo

A small Python example showing how to connect an Ollama chat model to custom Python functions. The model can choose a function based on a user's prompt, provide its arguments, and use the function's result to draft a response.

The project currently provides two tools:

- `calculate_hypotenuse(a, b)`: calculates the hypotenuse of a right-angled triangle.
- `calculate_product(a, b)`: multiplies two numbers.

**Note** - I'm running a local **llama3.2-local:latest** model renamed it to **llama:latest**

## How it works

The example in [`tool_caller.py`](./tool_caller.py) follows this flow:

1. **Define Python functions.** Each function converts its inputs to floats, performs a calculation, and returns the result.
2. **Describe the tools to the model.** `my_tools` declares each function's name, description, and JSON parameter schema. This lets the model know which tools are available and what arguments they accept.
3. **Route tool calls.** `available_tools` maps each advertised function name to its Python implementation.
4. **Send the prompt and tool definitions to Ollama.** The model may return a tool call with a function name and arguments, or answer without using a tool.
5. **Run the requested function.** Python looks up the function in `available_tools` and calls it with the model-provided arguments.
6. **Return the result to the model.** The result is added to the conversation as a tool message, and a follow-up chat request lets the model produce a final response.

This is **tool calling**, also known as **function calling**: the model selects and requests a function, while the application—not the model—executes the code.

## Requirements

- Python 3
- [Ollama](https://ollama.com/) installed and running locally
- The Ollama Python package
- The `llama:latest` model, as configured in the script

## Setup and run

Open a terminal in the project directory and install the Python client:

```bash
python3 -m pip install ollama
```

Download the model used by the script:

```bash
ollama pull llama
```

Make sure Ollama is running, then start the program:

```bash
python3 tool_caller.py
```

The current prompt in `run_conversation()` asks for the product of 3 and 4, so this run demonstrates `calculate_product`.

## Run both tools

The script has one active prompt at a time. To run each tool:

1. Open `tool_caller.py` and find `user_prompt` inside `run_conversation()`.
2. For multiplication, set it to:

   ```python
   user_prompt = "I have two numbers A and B. A is 3 and B is 4. What is the product?"
   ```

3. Save the file and run it from the project directory:

   ```bash
   python3 tool_caller.py
   ```

4. To try the hypotenuse tool, replace the prompt with:

   ```python
   user_prompt = "I have a right triangle with sides 3 and 4. What is the hypotenuse?"
   ```

5. Save and run the same command again:

   ```bash
   python3 tool_caller.py
   ```

The model chooses a tool based on the prompt. The examples are phrased to encourage it to call the matching function. If it answers directly instead, the program prints that response without executing a tool.

## Sample output

The model's wording can vary, but a multiplication run should look similar to:

```text
User Prompt: I have two numbers A and B. A is 3 and B is 4. What is the product?

[Tool Execution] Running calculate_product with a=3.0, b=4.0

Llama Final Answer:
The product of 3 and 4 is 12.
```

A hypotenuse run should look similar to:

```text
User Prompt: I have a right triangle with sides 3 and 4. What is the hypotenuse?

[Tool Execution] Running calculate_hypotenuse with a=3.0, b=4.0

Llama Final Answer:
The hypotenuse is 5.
```

The `[Tool Execution]` line confirms that Python ran the corresponding local function. The final answer is generated by the model after it receives the function's result.

The model decides whether to call a tool based on the prompt. If it answers directly instead, the program prints that response without running a function.

## Adding another tool

To add a function, make the same three updates in `tool_caller.py`:

1. Define a Python function.
2. Add its name, description, and parameter schema to `my_tools`.
3. Add a matching name-to-function entry in `available_tools`.

The function name must match across the tool schema and dispatch dictionary. Keep the schema's parameter names consistent with the Python function's arguments.
